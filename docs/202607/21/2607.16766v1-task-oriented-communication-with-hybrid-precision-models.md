## 摘要
边缘推理通过在网络边缘部署模型来规避云路由延迟，已成为人工智能服务蓬勃发展的有前景的解决方案。现有的边缘推理方法主要侧重于通过协同推理减少延迟，或设计轻量级模型以适应资源受限设备。这些解决方案通常分别解决通信和计算挑战，因此在传输效率、设备端处理成本和推理精度之间难以实现平衡的折衷。为弥补这一差距，本文提出了一种用于边缘推理的混合精度任务导向通信框架，以整体平衡通信、设备端计算和效用。在该框架中，边缘设备部署二值化前端，通过正交频分复用信号提取并传输二值特征，而边缘服务器上的全精度后端执行最终推理。为确保模型一致性，我们引入了一种针对分割推理定制的设备端二值化方法，并开发了一种集成的信道感知传输方案，该方案具有基于子载波的特征校准功能。此外，还开发了一种基于知识蒸馏的训练策略，并由专门的梯度估计器支持，以优化端到端系统并从全精度教师模型继承语义知识。在大规模ImageNet数据集上的大量实验证明了所提混合系统的优越性。我们的分析证实，该设计在通信效率、设备端计算成本和推理精度之间实现了最优折衷，优于现有的边缘推理解决方案。

## Abstract
Edge inference has emerged as a promising solution for the proliferation of artificial intelligence (AI) services by deploying models at the network edge to circumvent cloud-routing latency. Existing edge inference approaches mainly focused on either cooperative inference to reduce latency or lightweight model design to fit resource-constrained devices. These solutions often address the communication and computation challenges separately, and thus struggle to achieve a balanced trade-off among transmission efficiency, on-device processing cost, and inference accuracy. To bridge this gap, this paper proposes a hybrid-precision task-oriented communication framework for edge inference to holistically balance communication, on-device computation, and utility. In this framework, a binarized front-end is deployed on the edge device to extract and transmit binary features via orthogonal frequency-division multiplexing (OFDM) signals, while a full-precision back-end on the edge server performs the final inference. To ensure model consistency, we introduce an on-device binarization method tailored for split inference and develop an integrated channel-aware transmission scheme featuring subcarrier-based feature calibration. Furthermore, a knowledge distillation (KD)-based training strategy, supported by specialized gradient estimators, is developed to optimize the end-to-end system and inherit semantic knowledge from a full-precision teacher model. Extensive experiments on the large-scale ImageNet dataset demonstrate the superiority of the proposed hybrid system. Our analysis confirms that this design achieves an optimal trade-off among communication efficiency, on-device computational cost, and inference accuracy, outperforming existing edge inference solutions.

- **核心问题**：如何设计一个统一的边缘推理框架，在通信效率、设备端计算开销（FLOPs/BOPs）和推理精度之间实现最优权衡。
- **整体含义**：提出首个混合精度（Hybrid-Precision）任务导向通信框架，在资源受限的边缘设备上部署二值化前端（BNN），提取紧凑的二值特征并通过OFDM系统传输到边缘服务器，由全精度后端（FPNN）完成最终推理，从而协同优化三方面性能。

### 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：将深度神经网络分割，设备端仅运行二值化前端，产生二值特征；服务器端运行全精度后端。通过端到端知识蒸馏训练，并结合子载波校准、特征恢复和梯度估计，使得二值特征在无线信道下仍能保留任务相关信息。
- **关键技术细节**：
  - **设备端二值化（On-Device BNN）**：
    - 权重二值化：通过最小化重构误差`∥W_R - αW_B∥²`，得到最优二值权重`W_B* = sign(W_R)`和缩放因子`α* = ∥W_R∥₁/n`。
    - 激活二值化：使用可学习的偏置β<sub>0</sub>，`I_B = sign(I_R + β₀)`，引入弹性二值函数近似梯度（多项式step函数`appsgn`）。
    - 基本块设计：包含二值卷积（XNOR+popcount）、残差快捷连接、可学习偏置β₁, β₂和PReLU激活。
    - 传输前特征二值化：对最后输出的实值特征图按空间位置进行二值化，得到二进制特征`I_B`和空间缩放因子Υ，Υ被量化后与特征拼接为比特流`b`。
  - **子载波特征校准（Subcarrier-Based Feature Calibration）**：
    - OFDM系统中，根据各子载波的信道增益`|h(t,k)|²`降序排列，将调制后的特征段按可靠性顺序映射到子载波上，使关键特征优先分配到高质量信道上。
  - **服务器端二进制特征恢复（Binary Feature Recovery）**：
    - 将接收到的二进制特征建模为经过二进制对称信道（BSC），每个比特以概率p<sub>k</sub>翻转。
    - 推导出最优恢复掩码`ω<sub>k</sub>* = (1-2p<sub>k</sub>)·C_L·|I_{R,k}|/∑|I_{R,k}|`，由于无法获取每个|I_{R,k}|，近似为`ω<sub>k</sub>* = 1-2p<sub>k</sub>`，即根据信道质量软屏蔽受损比特。
    - 恢复后特征：`\hat{I}_{R}^{L+1} = Υ ⊙ Ω ⊙ \tilde{I}_{B}^{L+1}`。
  - **KD-based端到端训练**：
    - 损失函数：`L = E[λ CE(y, q_ϕ(y| \tilde{b})) + (1-λ) KL(p_T(y|x) ∥ q_ϕ(y|\tilde{b}))]`，其中λ平衡硬标签和教师软标签。
    - 隐式信息瓶颈：二值特征离散性、信道噪声、特征校准共同限制`I(X; \tilde{b})`，无需显式正则项。
    - 梯度传播：使用STE处理sign函数、数字调制/解调、信道的不可导性，对于激活采用`appsgn`函数近似导数，对于信道直接使用STE。
- **算法流程**（文字说明）：
  1. 设备端：输入x经L层二值化CNN前端，输出实值特征图I<sub>R</sub>；再按空间位置二值化为I<sub>B</sub>和缩放Υ，量化后拼接为比特流b。
  2. 传输：b经QAM调制，按子载波可靠性排序映射到OFDM符号，经多径信道发送。
  3. 服务器端：OFDM解调、MMSE/ZF均衡、QAM解调，得到受损比特流\tilde{b}；恢复为\tilde{I}_B；乘以掩码Ω（基于子载波BER）和缩放Υ，得到实值特征\hat{I}_R；输入全精度后端FPNN得到预测。
  4. 训练：预训练全精度教师模型（ResNet-50/101），使用KD损失+CE损失端到端优化整个系统，STE处理非可导部分。

### 3. 实验设计

- **数据集**：ILSVRC12 ImageNet（1000类，1.2M训练图像，50K验证图像）。
- **场景**：点对点OFDM系统，多径瑞利衰落信道（Ψ=8径，延迟扩展γ=4），子载波数N<sub>FFT</sub>=256，CP长度16，QAM-16调制，SNR变化（训练和测试分别设置5/10/15/20 dB）。
- **baseline**：
  - Server-Based FPNN：直接传输原始数据到服务器，使用全精度ResNet。
  - FPNN-Split-Compression：在分割点加入压缩模块（瓶颈通道数4/5/6），浮点值64-bit。
  - FPNN-Split-VQ：引入向量量化（码本256，7维向量/码字）。
  - Full BNN：15种代表性二值神经网络（XNOR-Net, ABC-Net, Bi-Real-Net, IR-Net, BNAS, NASB, Si-BNN, ProxyBNN, RBNN, ReActNet, ReCU, Bi-half, SiMaN, AdaBin, DIR-Net）。
- **模型架构**：基于ResNet-18/34/50/101系列，拆分点为中间层。设备端BNN有B-9（ResNet-18前半9层）和B-15（ResNet-34前半15层）；服务器端FPNN有FP-9/FP-19/FP-28/FP-79（对应ResNet-18/34/50/101的后半部分）。教师模型：全精度ResNet-101（用于ResNet-101混合模型）或ResNet-50（其他）。

### 6. 主要结论与发现

- 混合精度框架在**通信效率、设备计算开销和推理精度**三者之间实现了最优权衡，优于所有对比的端到端BNN和模型分割方案。
- 在ResNet-18/34骨干上，混合模型（B-9/FP-79等）的精度显著超过最先进的BNN（如ReActNet、ProxyBNN），同时设备端BOPs和FLOPs仅为传统BNN的一半左右。
- 在频率选择性衰落下，子载波校准机制有效提升精度和鲁棒性，尤其在高SNR训练时效果显著；低SNR训练可作为一种噪声正则化，增强极端信道下的泛化能力。
- 强大的服务器端后端（如ResNet-101）能从粗糙的二值特征中恢复高精度信息，使混合模型接近全精度上限。
