## 摘要
深度学习应用已广泛应用于边缘设备，以缓解访问云服务器的隐私和延迟问题。在深度神经网络设计过程中确定神经元数量以最大化性能并非直观。特别是，许多应用场景是实时的且具有严格的延迟约束，而传统的神经网络优化方法并不直接改变延迟关键型边缘系统中模型推理的时间成本。在这项工作中，我们提出了一种面向延迟的神经网络学习方法，以在满足延迟约束的同时优化模型以获得高精度。为了提高效率，我们还引入了一个通用的硬件定制延迟预测器，通过一次性训练过程来优化这一流程，从而学习满足延迟约束的模型。实验结果表明，与最先进的方法相比，我们的方法能够很好地适应“硬”延迟约束并实现高精度。在与原始模型相同的训练设置下，并在ImageNet-100数据集上满足34毫秒延迟约束时，我们将GoogLeNet的延迟从40.32毫秒降低到34毫秒，在NVIDIA Jetson Nano上精度仅下降0.14%。当结合量化时，我们的方法可进一步改进，GoogLeNet的精度仅下降0.04%。在NVIDIA Jetson TX2上，我们将VGG-19从119.98毫秒压缩到34毫秒，甚至将精度提高了0.5%；同时将GoogLeNet从20.27毫秒扩展到34毫秒，并将精度提高了0.78%。我们还开源了该框架，地址为https://github.com/ntuliuteam/ZeroBN。

## Abstract
Deep learning applications have been widely adopted on edge devices, to mitigate the privacy and latency issues of accessing cloud servers. Deciding the number of neurons during the design of a deep neural network to maximize performance is not intuitive. Particularly, many application scenarios are real-time and have a strict latency constraint, while conventional neural network optimization methods do not directly change the temporal cost of model inference for latency-critical edge systems. In this work, we propose a latency-oriented neural network learning method to optimize models for high accuracy while fulfilling the latency constraint. For efficiency, we also introduce a universal hardware-customized latency predictor to optimize this procedure to learn a model that satisfies the latency constraint by only a one-shot training process. The experiment results reveal that, compared to state-of-the-art methods, our approach can well-fit the 'hard' latency constraint and achieve high accuracy. Under the same training settings as the original model and satisfying a 34 ms latency constraint on the ImageNet-100 dataset, we reduce GoogLeNet's latency from 40.32 ms to 34 ms with a 0.14% accuracy reduction on the NVIDIA Jetson Nano. When coupled with quantization, our method can be further improved to only 0.04% drop for GoogLeNet. On the NVIDIA Jetson TX2, we compress VGG-19 from 119.98 ms to 34 ms and even improve its accuracy by 0.5%, and we scale GoogLeNet up from 20.27 ms to 34 ms and achieve higher accuracy by 0.78%. We also open source this framework at https://github.com/ntuliuteam/ZeroBN

- **整体含义**：本文提出一种**延迟导向的DNN架构学习方法**，能够直接以目标边缘设备上的实际推理延迟为硬约束，通过单次训练自动学习出满足延迟要求且精度最高的紧凑或扩展模型，解决了“模型-硬件”不匹配问题，为延迟关键型边缘智能系统提供了高效、通用的优化框架。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 利用**批归一化（BN）层中的可训练缩放因子γ**作为通道重要性的全局指标，通过动态零化γ（置零）并借助动量实现零化通道的恢复，从而在训练过程中自动探索最优子架构。
- 结合**机器学习延迟预测器**，直接根据当前模型架构预测其在目标设备上的延迟，避免重复上机测量，实现一次性训练满足延迟约束。
- 支持**模型压缩（复杂模型）** 和**模型缩放（简单模型）** 两种场景，对简单模型先统一缩放再压缩，消除搜索缩放因子的开销。

### 关键技术细节
1. **延迟关键紧凑学习（Latency-Critical Compact Learning）**：
   - **初始训练**：从零开始训练少量epoch，使BN的γ值能反映通道重要性（采用稀疏训练促进γ稀疏化）。
   - **Zero训练**：每隔k个epoch，基于γ绝对值全局排序，利用延迟预测器确定满足延迟约束的压缩率，设置γ阈值，将不重要的通道对应的γ和β置零（相当于移除该通道的输出）。
   - **恢复训练**：在Zero后的k-1个epoch中，由于动量优化器，被零化的γ和β能够从零恢复（梯度为零但动量积累提供非零更新），从而允许重要通道“复活”，扩大架构搜索空间。
   - **支持层剪枝**：在每个卷积层旁添加直接连接分支，根据层内γ绝对值总和决定是否移除整个层或移除分支，实现深度自适应调整。
   - 最终移除所有零化γ对应的通道，得到紧凑模型，无需额外微调。

2. **基于BP神经网络的延迟预测器**：
   - 构建包含16-12-1三层结构的BP网络，输入为单层运算（卷积、BN、池化等）的尺寸参数，输出为延迟。
   - 训练数据通过对参数空间进行规则采样+随机采样生成单层模型，在目标设备上实测延迟，并对延迟做正态分布变换以提高预测精度。
   - 预测完整模型时：先用单层预测器逐层预测延迟，再根据模型拓扑信息找出延迟加权最长路径，求和得到整体延迟。
   - 平均预测误差约6.12%，优于现有NN方法（13.52%）。

3. **延迟关键模型缩放（Latency-Critical Model Scaling）**：
   - 若原始模型延迟低于约束，则先**统一缩放**：对每层通道数乘以δ倍，层数也复制δ倍，使延迟超过约束。
   - 然后将扩展后的模型作为冗余模型，调用紧凑学习进行压缩，最终得到满足约束且精度更高的模型，无需单独搜索宽度/深度缩放因子。

## 7. 优点

- **直接优化延迟**：以实际硬件延迟为硬约束，替代FLOPs等间接指标，更符合边缘实时应用需求。
- **单次训练**：无需预训练和微调的三阶段流程，通过动态Zero-Recovery实现一次性训练即得到满足约束的模型，大幅降低时间成本。
- **全局重要性排序**：基于BN的γ值跨层排序，并允许零化通道恢复，拓展了架构搜索空间，优于固定每层剪枝率的局部方法。
- **通用延迟预测器**：基于BP网络，轻量且准确，可推广至其他硬件指标（如能耗、内存），且训练数据生成成本低。
- **统一框架**：同时支持模型压缩和缩放，适应复杂模型（过高延迟）和简单模型（过低延迟）的优化。
- **开源实现**：代码已公开，便于复现和扩展。
