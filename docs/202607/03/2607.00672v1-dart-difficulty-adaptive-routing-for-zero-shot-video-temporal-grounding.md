## 摘要
零样本视频时序定位（VTG）旨在无需特定任务训练的情况下，根据自然语言查询在未裁剪视频中定位事件。现有方法依赖帧-查询特征匹配，这足以处理简单事件，但在处理需要理解时序顺序和因果结构的复杂多阶段查询时表现不佳——我们将这种差异称为推理鸿沟。我们提出DART（面向时序定位的难度自适应路由），通过将难度感知路由与大型视觉语言模型中的结构化推理相结合来弥合这一鸿沟。基于查询条件化的行列式点过程（DPP）发挥双重作用：选择多样化且与查询相关的关键帧作为时序证据，并提供谱熵作为难度指标。简单查询被路由到快速路径进行直接预测，而复杂查询则遵循慢速路径，通过时序标记提示将定位分解为全局事件分析、逐帧时序角色标注和边界提取。在Charades-STA和ActivityNet Captions数据集上，DART在多个同分布和不同分布场景下均取得了最先进的零样本性能，相较于最强基线，mIoU最高提升3.5个点，同时使用的帧数减少7倍以上。项目主页见https://dart-vtg.github.io/。

## Abstract
Zero-shot video temporal grounding (VTG) localizes events in untrimmed videos from natural language queries without task-specific training. Existing methods rely on frame-query feature matching, which suffices for simple events but struggles with complex multi-stage queries that require understanding temporal ordering and causal structure -- a disparity we call the reasoning gap. We propose DART (Difficulty-Adaptive Routing for Temporal Grounding), which bridges this gap by coupling difficulty-aware routing with structured reasoning in large vision-language models. A query-conditioned Determinantal Point Process (DPP) serves a dual role: selecting diverse, query-relevant keyframes as temporal evidence, and providing spectral entropy as a difficulty indicator. Simple queries are routed to a Fast path for direct prediction, while complex queries follow a Slow path with Temporal Markup Prompting, which decomposes localization into global event analysis, per-frame temporal role annotation, and boundary extraction. On Charades-STA and ActivityNet Captions, DART achieves state-of-the-art zero-shot performance across both identically distributed and multiple out-of-distribution settings, improving mIoU by up to 3.5 points over the strongest baseline while using over 7 times fewer frames. The project homepage is available at https://dart-vtg.github.io/.

## 1. 核心问题与整体含义（研究动机和背景）

- **任务**：零样本视频时序定位（Zero-shot VTG），即无需任务特定训练，根据自然语言查询在未裁剪视频中定位事件起止时间。
- **现有方法的局限**：现有基于帧-查询特征匹配的零样本方法（如TFVTG、TAG）对简单事件有效，但无法处理需要理解时序顺序、因果关系的复杂多阶段查询。作者将这种性能差距称为**推理差距**（reasoning gap）。实验表明，在ActivityNet Captions的复杂查询子集上，最强基线方法mIoU下降11.6个点。
- **动机**：链式思维（CoT）提示可激活大型视觉语言模型（LVLM）的推理能力，但直接应用面临两个挑战：(1) 如何为CoT获得紧凑且充分的时序证据？现有均匀采样或固定步长采样可能遗漏关键阶段或引入大量无关帧作为干扰。(2) 如何自适应决定何时需要推理？对所有查询不加区分地使用推理会带来不必要的延迟，并可能因中间步骤误差累积而降低性能。
- **研究意义**：弥合零样本VTG中的推理差距，使模型既能高效处理简单事件，又能精确处理复杂事件。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 提出**DART**（Difficulty-Adaptive Routing for Temporal Grounding），通过**难度感知路由**将简单查询导向快速路径（Fast path，直接预测），复杂查询导向慢速路径（Slow path，结构化推理）。
- 使用**查询条件化的行列式点过程（Query-conditioned DPP）** 完成双重任务：既能选择多样化、与查询相关的关键帧，又能通过谱熵提供难度指标。
- 慢速路径采用**时序标记提示（Temporal Markup Prompting, TMP）**，将定位分解为三个步骤：全局事件分析、逐帧时间角色标注、边界提取。

### 2.2 关键技术细节

#### （1）查询条件化DPP关键帧选择
- 构建查询条件化核矩阵 $\tilde{L}$：先构建基础相似性核 $L_{ij} = k_v(f_i, f_j) \cdot k_t(t_i, t_j)$（视觉高斯核×时间高斯核），再用查询相关权重 $w_i = \sigma(f_i^\top q / \tau)$ 加权：$\tilde{L}_{ij} = \sqrt{w_i} L_{ij} \sqrt{w_j}$。
- 贪婪选择：每次选择边际增益 $\Delta(e|S) = \log \det(\tilde{L}_{S\cup\{e\}}) - \log \det(\tilde{L}_S)$ 最大的帧。根据推导，该增益可分解为多样性项和查询相关性项。
- 自适应预算：当相对增益 $\Delta_k / \Delta_1 < \varepsilon$ 时停止选择，自动为每个（视频，查询）对确定关键帧数量。

#### （2）谱熵作为难度指标
- 对 $\tilde{L}$ 进行特征分解，将特征值归一化为概率分布 $q_i = \lambda_i / \sum \lambda_j$，计算谱熵 $H_{\text{spectral}} = -\frac{1}{\log M} \sum q_i \log q_i \in [0,1]$。
- 简单事件能量集中在少数特征值（低熵），复杂事件能量分散（高熵）。设置阈值 $\theta$，$H_{\text{spectral}} \leq \theta$ 路由到快速路径，否则到慢速路径。

#### （3）双路径定位
- **快速路径**：直接由LVLM根据所选关键帧和时间戳输出起止时间。
- **慢速路径（时序标记提示TMP）**：
  - Step 1：全局时间推理——分解查询中的关键动作，识别时序关系，概述事件时间范围。
  - Step 2：逐帧时间角色标注——为每个关键帧分配角色（before/start/during/end/after），要求单调非递减。
  - Step 3：边界提取——第一个“start”帧时间戳作为$t_s$，最后一个“end”帧时间戳作为$t_e$。

## 6. 主要结论与发现
- DART在IID和OOD所有设置上均达到零样本SOTA，在Charades-STA上mIoU达48.93%，ActivityNet Captions上达39.89%，比最强基线TAG分别高3.24和3.34个百分点。
- 消融表明：DPP关键帧选择贡献最大（-4.23 mIoU）；自适应预算优于固定K；结构化TMP优于通用CoT；难度自适应路由优于纯快速或纯慢速。
- 谱熵与难度高度相关：低熵区间mIoU=49.2%，高熵区间仅27.4%（Fast path评估），验证了熵作为难度指标的可靠性。
- 推理效率显著提升：使用12帧（基线86帧）达到3.9秒/查询，比TFVTG快17%，且精度更高。

## 7. 优点
- **新颖性**：首次将难度自适应路由引入零样本VTG，利用DPP同时完成关键帧选择和难度估计，巧妙统一了证据提取和路由决策。
- **有效性**：通过结构化时序标记提示（TMP）提供任务特定的推理步骤，比通用CoT更精准。
- **通用性**：在多种分布外场景下均表现优异，证明结构化推理比特征匹配更具泛化能力。
- **效率**：自适应路由使简单查询避免不必要的推理，大幅节省计算成本，整体比基线更高效。
- **可解释性**：谱熵提供了可解释的难度度量，帮助理解模型行为。

## 8. 不足与局限
- **依赖LVLM能力**：DART的性能受限于底层LVLM（LLaVA-1.6-7B）的视觉理解和推理能力，若换成更弱或更强的骨干可能波动。
- **路由阈值需手动设定**：超参数 $\theta$（实验中设为0.45）需要调参；虽然提供了谱熵分析，但尚未实现全自动调节。
- **实验覆盖**：仅测试了两个标准数据集（Charades-STA和ActivityNet Captions），且视频类型以室内活动和日常动作居多，尚未在细粒度或长视频（如电影、体育赛事）上评估。
- **关键帧数量方差**：自适应预算依赖阈值$\varepsilon$，可能在某些场景低估或高估所需帧数。
- **慢速路径计算开销**：虽然总推理时间有优势，但慢速路径本身单次推理时间（5.1秒）仍高于TFVTG（4.7秒），若大部分查询为复杂查询，总时间可能增加。
- **未测试多模态骨干变体**：仅使用了LLaVA-1.6，未探索其他LVLM（如InternVL, BLIP-2等）下的泛化性。
