## 摘要
现代视频对象分割（VOS）涉及跟踪和分割用户指定的目标。虽然近期方法在单目标场景中取得了显著性能，但将其扩展到多目标场景通常需要为每个单独目标复制单目标处理流程，导致帧率（FPS）下降且延迟随目标数量增加而无界增长。基于Segment Anything 2（SAM2），我们提出SAM-MT，通过将模型转化为实时多目标视频分割的交互式框架来解决这一问题。SAM-MT使用显式查询来表示不同的个体目标，同时使用共享表示来处理全局上下文。它采用解耦掩码注意力来保持个体身份免受跨目标干扰，利用稀疏内存实现稳定的时间演化，并配备专门策略处理遮挡和防止重叠。SAM-MT成功将延迟与目标数量解耦，实现了与单目标基线相当的实时速度（10个目标超过36 FPS），同时保持了SAM2强大的视频分割性能。

## Abstract
Modern Video Object Segmentation (VOS) involves tracking and segmenting user-specified targets. While recent approaches have achieved remarkable performance in single-target scenarios, extending them to multi-target settings typically involves replicating the single-target processing for each individual object, resulting in reduced frame rates (FPS) with unbounded latency as target count increases. Built upon Segment Anything 2 (SAM2), we propose SAM-MT, which addresses this by transforming the model into an interactive framework for real-time Multi-Target video segmentation. SAM-MT uses explicit queries to represent different individual targets, in parallel with a shared representation for global context. It employs decoupled masked attention to keep individual identities distinct from cross-target interference, and sparse memory for stable temporal evolution, along with specialized strategies for occlusion handling and overlap prevention. SAM-MT successfully decouples latency from the number of targets, achieving real-time speed on par with single-target baselines (>36 FPS for 10 targets) while maintaining SAM2's robust video segmentation performance.

## 1. 核心问题与整体含义（研究动机和背景）

**研究动机**：现有视频对象分割（VOS）方法（包括最先进的SAM2及其扩展）在处理多个用户指定目标时，通常采用“为每个目标复制单目标处理流程”的策略。这种策略导致计算成本和延迟随目标数量线性增长，帧率（FPS）急剧下降，无法满足自动驾驶、机器人等实时应用对高帧率、多目标同时跟踪分割的需求。简单的“合并所有目标为单个掩码”会丢失个体身份，且不规则的合并形状导致模型难以跟踪。

**整体含义**：本文旨在构建一个**实时交互式多目标视频分割框架**，使延迟与目标数量解耦，在保持单目标级别推理速度的同时，准确维持每个目标的身份一致性。这是首个在框架层面解决SAM家族多目标瓶颈的工作。

## 2. 方法论

### 核心思想
基于SAM2架构，引入**显式目标查询**（target queries）并行表示每个个体目标，同时保留**共享全局上下文表示**，通过**解耦掩码注意力**（decoupled masked attention）防止跨目标干扰，并设计**查询基稀疏内存**（query-based sparse memory）实现稳定时间演化。

### 关键技术细节
- **可扩展目标查询**：每个用户指定的目标分配一个独立的ID感知查询，支持任意数量目标（初始帧每个目标可对应多个点击点，后续帧每个目标一个查询）。
- **解耦掩码注意力**：在解码器的自注意力层中，对同一目标内部的查询允许完全交互，不同目标之间的查询完全屏蔽（−∞），但所有目标查询均可与全局查询交互。数学定义如公式(2)-(4)所示，确保每个目标保持身份特异性。
- **查询合并**（初始帧）：对每个目标多个点的查询，通过轻量MLP加权头合并为单一目标查询（公式(5)），后续帧直接使用传播的查询。
- **查询基稀疏内存**：以FIFO方式存储最近T帧所有目标的查询（每个目标仅1个token），大幅降低每帧存储开销（从SAM2的HW个稠密token降至1个Query token），支持更长时序窗口（窗口大小16）。
- **身份变换器**（Identity Transformer）：在后续帧中，当前帧目标查询通过交叉注意力从稀疏内存中检索各自的历史查询，并使用身份感知掩码（公式(8)）确保每个查询只关注自身历史，防止身份漂移。
- **训练策略**：
  - 两阶段训练：先图像级静态训练，再视频序列训练。
  - 步进采样（Strided Sampling）：结合连续帧和4帧间隔采样，覆盖32帧窗口，增强对遮挡和重现的鲁棒性。
  - 重叠惩罚损失：鼓励不同目标掩码互斥，减少像素级歧义（公式(9)）。
  - 损失函数：个体损失（Focal + Dice + 重叠损失） + 全局损失（Focal + Dice + IoU + 目标分数损失）。

## 6. 主要结论与发现

1. **精度领先**：SAM-MT在MOSEv2上达到43.0 J&F˙，超越SAM2.1-B+（41.1）和Cutie（42.8）；在LVOSv2/v1上分别提升2.0和2.3个点。
