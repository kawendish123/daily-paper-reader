## 摘要
当前的视觉语言模型在处理长达数小时的视频时存在困难，因为处理完整的视觉序列会导致令牌爆炸和注意力稀释。为了解决这一问题，我们提出了MemDreamer来解耦感知与推理，将长视频理解转变为智能体探索过程。作为一个即插即用的框架，它增量式地流式传输视频以构建层级图记忆（Hierarchical Graph Memory），这是一种自上而下的三层架构，用于语义抽象，并由一个捕获时空和因果关系的基础图进行锚定。在推理阶段，推理模型采用智能体工具增强的检索，通过观察-推理-行动循环在层级间导航、搜索节点并遍历逻辑边。实验表明，MemDreamer在四个主流基准测试上达到了最先进的结果，将与人类专家的差距缩小至仅3.7个百分点。它将推理上下文窗口限制为仅完整上下文摄入的2%，同时实现了12.5个百分点的绝对准确率提升。此外，统计分析揭示了视觉语言模型在逻辑推理和长视频理解基准测试性能之间的强正线性相关性，建立了智能体能力扩展作为多模态理解的新范式。

## Abstract
Current Vision-Language Models struggle with hours-long videos because processing full-length visual sequences induces prohibitive token explosion and attention dilution. To overcome this, we introduce MemDreamer to decouple perception and reasoning, shifting long-video understanding into an agentic exploration process. As a plug-and-play framework, it incrementally streams videos to construct a Hierarchical Graph Memory, a top-down three-tier architecture for semantic abstraction, anchored by a foundational graph capturing spatiotemporal and causal relations. During inference, the reasoning model employs agentic tool-augmented retrieval, navigating hierarchies, searching nodes, and traversing logical edges via an Observation-Reason-Action loop. Experiments show MemDreamer achieves SOTA results across four mainstream benchmarks, narrowing the gap with human experts to only 3.7 points. It constrains the reasoning context window to merely 2% of full-context ingestion while delivering a 12.5 point absolute accuracy gain. Furthermore, statistical analysis uncovers a strong positive linear correlation between an VLM's performance on logic reasoning and long-video understanding benchmarks, establishing agentic capability scaling as a new paradigm for multimodal comprehension.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：当前视觉语言模型（VLM）在处理小时级长视频时，由于全量序列输入导致 token 爆炸（例如 2 小时视频 1 FPS 采样产生 1.6M tokens）和注意力稀释（Attention Dilution），引发“lost in the middle”现象，严重削弱长程推理能力。
- **整体含义**：该论文提出 MemDreamer，将长视频理解从被动式的 token 消费转变为主动的智能体探索过程。通过将感知与推理解耦，利用流式构建的层次图记忆（Hierarchical Graph Memory）和工具增强的智能体检索机制，在不扩展上下文窗口的前提下实现高效、精确的长视频理解。该工作首次揭示了逻辑推理能力与长视频理解性能之间的强正线性相关性，并为多模态理解开辟了“智能体能力扩展”的新范式。

## 2. 方法论

### 2.1 核心思想
- **解耦感知与推理**：使用一个感知模型（Perception Model）流式处理视频并构建纯文本的层次图记忆；推理阶段使用另一个推理模型（Reasoning Model）通过智能体工具在与记忆交互中逐步获取证据，全程不再访问原始视频帧。
- **即插即用框架**：不依赖特定的感知或推理模型，支持多种 backbone（如 Gemini 系列、Qwen3-VL）。

### 2.2 关键技术细节
#### （A）层次图记忆（Hierarchical Graph Memory）
- **三层架构**：
  - 顶层：Video Root（视频全局摘要）
  - 中层：Super Events（叙事阶段，10–20 个）
  - 底层：Macro Events（详细事件，每个都为语义独立的片段）
- **底层子图（Subgraph）**：每个 Macro Event 内部包含实体节点（VEi）和微事件节点（VMi），通过三类边连接：
  - 空间属性边（VEi ↔ VEi）：描述布局、位置等静态关系
  - 主客边（VEi ↔ VMi）：描述实体与事件的参与关系
  - 时间因果边（VMi → VMi）：描述时间顺序与因果关系
- **构建流程**：
  1. **流式自适应分割**：利用感知模型在滑动窗口（τ=10 min）内识别语义边界，切割出完整的 Macro Events。
  2. **向下子图提取**：对每个 Macro Event 提取细粒度子图（实体、微事件、边）及文本摘要。
  3. **向上层次聚合**：将邻近的 Macro Events 合并为 Super Events，并最终得到 Video Root。

#### （B）智能体工具增强检索（Agentic Tool-Augmented Retrieval）
- **工具箱（Tool Bank）**：包含 7 个工具，分为 3 类：
  - **层次导航工具**：GetSummary、GetSuperEvent、GetMacroEvent、GetSubgraph（用于自上而下逐层浏览）
  - **精确搜索工具**：SearchNodes（语义检索）、SearchByTime（时间检索）
  - **图遍历工具**：GetRelationGraph（沿边跳转，追踪多跳因果链）
- **Observation-Reason-Action 循环**：
  - 每步：推理模型根据当前问题和历史轨迹选择并执行一个工具；
  - 获取观察结果后，模型仅提取与问题相关的证据（Clue），而非直接累积原始输出；
  - 当前动作与线索追加到轨迹中，直到模型认为证据充分可直接作答。
- **最大工具调用步数**：默认 Tmax = 12，可在 5.9K–6.3K token 的推理上下文内完成。

## 6. 主要结论与发现

1. **SOTA 性能**：MemDreamer 在 LVBench、LongVideoBench、Video-MME、EgoSchema 四个基准上均取得最高分，与人类专家在 LVBench 上的差距缩小至 **3.7 个百分点**。
2. **上下文窗口大幅压缩**：推理上下文仅需 5.9K–6.3K tokens（仅为端到端全量输入的 2%），同时准确率提升 12.5 个百分点（Gemini-3.1-Pro 从 78.2 → 90.7）。
3. **推理能力与长视频理解强正相关**：在端到端范式中，LVBench 与 AIME2025 的相关性 R=0.702（p=0.052，不显著）；引入 MemDreamer 后 R=0.897（p<0.01，显著）。说明解耦后模型可直接利用其逻辑推理能力。
4. **层次图记忆的必要性**：同时使用层次拓扑和因果图比单独使用其中一种效果更好（Hierarchical-Graph 90.7 vs. Flat-Graph 84.8 vs. Hierarchical-Chunk 86.3）。
5. **工具增强检索的必要性**：完整的工具集（导航+搜索+图遍历）显著优于纯语义嵌入（90.7 vs. 70.5）或仅搜索（80.2）或全量记忆输入（78.9）。

## 7. 优点

- **创新性**：首次提出“解耦感知与推理”范式，将长视频理解构建为智能体探索任务，并通过层次图记忆结构化支持多步推理。
- **即插即用性**：不限制具体的感知或推理模型，可适配多种现有的闭源/开源 VLM，易于迁移。
- **高效性**：推理 token 消耗极低（~6K），显著降低计算成本。
- **全面实验**：在多个标准基准、多种 backbone、细致消融上验证了方法的有效性，并提供了统计学分析，说服力强。
- **清晰的因果分析**：通过相关性分析对“上下文干扰导致推理能力被抑制”这一假设提供了定量证据，对未来研究具有指导意义。

## 8. 不足与局限

- **对感知模型的依赖**：层次图记忆的构建依赖于强感知模型（本文采用 Gemini-3.1-Pro）进行语义分割、子图提取和聚合。较弱或误分割较多的感知模型可能导致记忆质量下降（虽然表 6 显示韧性较强，但仍是风险点）。
- **纯文本记忆的局限**：整个推理过程只使用文本记忆，不访问原始帧，意味着微妙的视觉细节（如细微颜色、动态表情）可能丢失，影响细粒度问答。
- **工具集固定**：七种工具是预设的，无法根据任务动态扩展。对于全新类型的问题（如需要外部知识或跨视频检索），可能不够灵活。
- **延迟与实时性**：构造记忆需要流式处理整个视频（尽管是离线可并行），且智能体循环需要多步调用 API，端到端推理延迟较高，可能不适合实时场景。
- **未见训练细节**：论文为即插即用，无需训练新模型，因此未提供任何训练阶段成本。但若需在特定领域优化记忆构建提示词，可能需要额外调试。
- **数据集局限**：LVBench 等基准以新闻、纪录片等长视频为主，是否泛化到其他长视频类型（如虚拟世界、实时监控）仍需验证；EgoSchema 的结果提升较小（+11.4），可能因为自我中心视频的背景噪声对文本记忆构建的挑战更大。
- **偏差风险**：未讨论不同群体/语言/文化的视频在实验中的表现差异；相关性分析基于 8 个模型，样本量较小（p 值虽显著，但统计效力有限）。
