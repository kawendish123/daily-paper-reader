## 摘要
在真实世界监控中部署视频异常检测（VAD）面临着对高层次语义以确保有效性的需求与边缘设备有限计算资源之间的根本矛盾。视觉语言模型（VLM）提供了丰富的开放词汇语义，但其延迟和计算成本阻碍了在设备上的部署。为应对这一挑战，我们提出MemoVAD，一种边缘-云协同框架，可选择性地将VLM语义整合到流式VAD中。MemoVAD在边缘端使用轻量级检测器和因果时间上下文编码器（TCE）建模时间依赖关系，运行大部分推理。具体而言，我们引入基于主观逻辑的不确定性感知门控（UAG）策略，以建模感知不确定性，并仅对高不确定性和语义新颖的片段查询基于云的VLM。此外，设计了动态语义内存（DSM），用于缓存经VLM验证的原型以实现高效检索，使边缘模型能够通过语义适配器逐步融入VLM级语义。通过在真实边缘设备上对UCF-Crime和XD-Violence数据集进行的实验表明，MemoVAD在显著降低通信开销的同时超越了当前最先进的性能。

## Abstract
Deploying Video Anomaly Detection (VAD) in real-world surveillance faces a fundamental tension between the demand for high-level semantics to ensure effectiveness and the limited computational resources of edge devices. Vision-Language Models (VLMs) provide rich open-vocabulary semantics, but their latency and computational cost preclude on-device deployment. To address the challenge, we propose MemoVAD, an edge-cloud collaborative framework that selectively incorporates VLM semantics into streaming VAD. MemoVAD runs most inference on the edge with a lightweight detector and a causal Temporal Context Encoder (TCE) to model temporal dependencies. Specifically, we introduce an Uncertainty-Aware Gating (UAG) policy grounded in Subjective Logic to model perceived uncertainty and query the cloud-based VLM only for high-uncertainty and semantically novel clips. Besides, a Dynamic Semantic Memory (DSM) is designed to cache VLM-verified prototypes for efficient retrieval, enabling the edge model to progressively incorporate VLM-level semantics via a semantic adapter. Experiments on UCF-Crime and XD-Violence datasets via a real edge device show that MemoVAD substantially reduces communication overhead while surpassing state-of-the-art performance.

- **整体含义**：需要设计一种边缘-云协同框架，既保持边缘端低延迟推理，又能选择性集成云端VLM的高层语义能力，从而在资源受限条件下实现高效、准确的视频异常检测。

## 2. 论文提出的方法论

- **核心思想**：提出MemoVAD框架，采用“边缘为主、云端为辅”的协同模式。边缘端运行轻量级检测器处理大部分推理，仅在模型自身不确定或遇到语义新颖的片段时才查询远程VLM，并将VLM验证过的语义原型缓存到边缘端动态语义内存中，后续相似事件可直接检索使用，避免重复查询云端。
- **关键技术细节**：
  - **边缘端检测器**：使用冻结的VideoMAE-Small作为视觉骨干，提取运动特征；后接一个2层因果Transformer编码器（TCE），对固定长度历史窗口建模时间依赖。
  - **不确定性感知门控（UAG）**：基于主观逻辑（Subjective Logic）中的证据学习，对每个片段预测Normal和Anomaly两类的非负证据，推导Dirichlet分布参数和感知不确定性$u_t = K / S_t$（$K=2$）。当$u_t > \tau_{unc}$（高不确定性）且记忆检索相似度$s_{retrieval} < \tau_{sim}$（语义新颖）时，触发VLM查询。该策略有效区分了难样本和分布外样本。
  - **动态语义内存（DSM）**：内存结构为键值对，键是学生特征$h^{pre}_t$，值是VLM验证后的语义嵌入$z_{vlm}$。通过多头交叉注意力从内存中检索语义信息$m_t$，并计算最大余弦相似度$s_{retrieval}$用于门控。内存更新采用在线语义多样性替换策略：保留最不冗余的关键词（即与其他键最大余弦相似度最小的键），避免灾难性遗忘，维持固定预算$N_{max}=2048$。
  - **语义适配器模块（SAM）**：将VLM语义嵌入通过线性投影和瓶颈适配器与边缘学生特征融合，采用门控残差连接（初始$\alpha=0$防止负迁移），得到最终增强特征$h^{enriched}_t$。
- **损失函数**：包含MIL排序损失$L_{mil}$、语义蒸馏损失$L_{distill}$（仅对触发VLM的片段施加，stop-gradient处理VLM侧）、时间平滑损失$L_{smooth}$、门控头损失$L_{gate}$（基于证据深度学习，仅对每个袋中最高分片段监督）。总损失为加权和。
