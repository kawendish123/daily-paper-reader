## 摘要
现代边缘系统级芯片（SoC）集成了异构处理单元（PU），如CPU、GPU和NPU，但当前的推理栈将整个模型映射到单个PU，导致显著的性能和能效损失。新兴架构如状态空间模型（SSM）、Kolmogorov-Arnold网络（KAN）和多阶段视觉-语言-动作（VLA）流水线进一步加剧了这一问题，其多样化的算子特性并不均匀地适用于任何单一PU。我们提出了BIDENT，一个统一的边缘异构推理的算子级编排框架，根据分析出的执行特性将单个算子映射到最合适的PU。BIDENT将算子到PU的分配表述为加权执行图上的最短路径问题，能够在成本模型下针对延迟和能耗最小化目标实现高效最优调度。与依赖模型特定启发式或粗粒度分区的先前工作不同，BIDENT是模型无关的，并在单一公式中联合支持顺序执行、独立算子间的模型内并行以及多模型并发调度。我们在Intel Core Ultra SoC上实现了BIDENT，并在跨越CNN、Transformer、SSM、KAN、脉冲网络和多阶段流水线的10个模型家族上进行了评估。通过模型内并行，BIDENT实现了高达1.60倍的加速；通过利用原本空闲的计算资源，在190个多模型组合上实现了3.42倍的几何平均加速。顺序异构映射的增益较为温和（最高1.58倍，几何平均1.09倍），而能量感知调度在并发设置下平均减少了48.2%的能耗。这些结果表明，算子级编排（而非模型级映射）是充分利用下一代边缘AI异构性的关键抽象。

## Abstract
Modern edge System-on-Chips (SoCs) integrate heterogeneous processing units (PUs) such as CPUs, GPUs, and NPUs, yet current inference stacks map entire models to a single PU, leaving significant performance and energy efficiency on the table. This is exacerbated by emerging architectures such as state-space models (SSMs), Kolmogorov-Arnold networks (KANs), and multi-stage vision-language-action (VLA) pipelines, whose diverse operator characteristics are not uniformly suited to any single PU. We present BIDENT, a unified operator-level orchestration framework for heterogeneous edge inference that maps individual operators to the most suitable PU based on profiled execution characteristics. BIDENT formulates operator-to-PU assignment as a shortest-path problem over a weighted execution graph, enabling efficient and optimal scheduling under the cost model for both latency- and energy-minimization objectives. Unlike prior work relying on model-specific heuristics or coarse-grained partitioning, BIDENT is model-agnostic and jointly supports sequential execution, intra-model parallelism across independent operators, and multi-model concurrent scheduling in a single formulation. We implement BIDENT on an Intel Core Ultra SoC and evaluate it across 10 model families spanning CNNs, Transformers, SSMs, KANs, spiking networks, and multi-stage pipelines. BIDENT achieves up to 1.60x speedup via intra-model parallelism and a 3.42x geometric mean speedup across 190 multi-model combinations by utilizing otherwise idle compute. Sequential heterogeneous mapping yields more modest gains (up to 1.58x, 1.09x geometric mean), while energy-aware scheduling reduces energy consumption by 48.2% on average in concurrent settings. These results show that operator-level orchestration, not model-level mapping, is the key abstraction for fully exploiting heterogeneity in next-generation edge AI.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题现状**：现代边缘SoC（如Intel Core Ultra）集成了CPU、GPU、NPU等多个异构处理单元（PU），但现有推理框架（如OpenVINO、TensorRT）强制执行“全模型单PU”映射，无法利用算子级别的PU亲和差异，导致：
  - **性能损失**：非标准算子（如FFT、scan、spline）在不匹配的PU上执行极慢（高达10倍以上）。
  - **能效浪费**：单一PU可能不是能耗最优选择。
  - **资源闲置**：同一模型内数据无关的算子无法并发执行，多模型并发时PU利用率低。
- **新兴架构加剧问题**：SSM（Mamba）、KAN、Hyena、VLA流水线等模型包含多种异构算子，其最佳PU因类型和尺寸而异。
- **论文含义**：提出**算子级编排**（operator-level orchestration）作为关键抽象，通过将每个算子映射到最适PU来全面释放异构SoC潜力。

## 2. 论文提出的方法论

### 核心思想
- BIDENT将算子到PU的分配建模为**加权有向执行图上的最短路径问题**，通过Dijkstra算法高效求解最优映射（延迟或能耗最小化）。
- 统一支持三种执行场景：**顺序执行**、**模型内并行**（独立算子并发）、**多模型并发**。

### 关键组件
1. **Profiler（离线分析器）**
   - 对每个融合算子（fused operator）在每个PU上测量四类成本：H2D传输、内核调度、内核执行、D2H传输。
   - 也测量持续功率（用于能量优化）。
   - 若某PU不支持某算子，则节点被省略，搜索自动选择可用PU。

2. **Execution Graph Builder（执行图构建器）**
   - **顺序图**：节点 = (算子, PU)，边 = 执行成本 + 跨PU数据传输成本。
   - **并行图**：通过拓扑遍历将DAG分为**阶段**（phase）和**分支**（branch），分支间可并发，执行性最大分支延迟（考虑跨PU争用调整因子SF）。
   - **多模型并发图**：使用对齐Dijkstra或联合(i,j)状态空间搜索，同时追踪两个模型的进度，支持同PU上的并发执行成本（实测）。

3. **Search Engine（搜索引擎）**
   - 使用动态规划（或Dijkstra）在DAG上求解最短路径，时间复杂度O(N·K²)，N为算子数，K为PU数，亚毫秒级。
   - 能量模式：边权重 = 延迟 × 功率，搜索最小能量。

### 算法流程（简化文字说明）
1. 离线分析各模型所有融合算子在各PU上的延迟和功率。
2. 根据模型DAG构建执行图：顺序场景构建线性层图；并行场景识别阶段和分支；多模型场景联合构建状态空间。
3. 在图上运行最短路径搜索，得到每个算子（或分支）的PU分配。
4. 输出静态调度表，推理时直接应用，无运行时开销。

## 6. 主要结论与发现

- **顺序异构映射**：几何平均加速 **1.09×**（1.01–1.58×），能量平均减少 **9.2%**。SNN-VGG9获得最大加速（1.58×），π0.5获得1.23×。
- **模型内并行**：最大加速 **1.60×**（ViT），Lavish、Mamba等也有明显提升。几何平均加速高于顺序（具体值未列，但从表中可见ViT 1.55×、Mamba 1.29×等）。
- **多模型并发**：190个模型对的**几何平均加速 3.42×**，最高达22.4×（KAN+LAVISH）。能量平均减少 **48.2%**。
- **关键发现**：对于算子类型均匀的模型（如LLaMA全层为大矩阵乘法），异构收益有限（~1.02×），验证了异构编排主要从**非均匀算子**和**并行/并发**中获益。
- **能量 vs 延迟**：能量优化路径直接选择低功耗PU，平均节省9.2%远超延迟优化路径的3.7%。但能量优化会牺牲部分延迟（几何平均1.03× vs 1.09×）。

## 7. 优点

1. **统一且简洁的公式**：将异构调度转化为图上的最短路径问题，支持顺序、并行、并发三种模式及两种优化目标。
2. **模型无关**：不依赖特定架构启发式，支持CNN、Transformer、SSM、KAN、SNN、VLA等广泛模型。
3. **最优性保证**：Dijkstra/动态规划在给定成本模型下保证全局最优。
4. **实际硬件实现**：在真实Intel Core Ultra SoC上端到端实现，集成OpenVINO后端，零运行时开销。
5. **全面实验**：涵盖10个模型家族、19个精度配置、190个并发对，以及延迟/能量对比。
6. **能量显著节省**：多模型并发时平均48.2%能耗降低，对电池供电边缘设备意义重大。
7. **对非标准算子友好**：自动将不支持/高代价算子路由到合适PU，避免编译失败或回退。

## 8. 不足与局限

1. **平台单一**：仅在Intel Core Ultra SoC上评估，结果在其他异构SoC（如高通、NVIDIA Jetson）上可能不同。
2. **静态调度**：调度离线生成，无法适应运行时动态变化（如热节流、多进程干扰、动态形状）。论文未来工作计划探索动态扩展。
3. **争用模型简化**：模型内并行使用固定争用因子，多模型并发用实测对级成本，缺少更精细的带宽模型。
4. **无动态输入适应**：假设算子形状固定，对于输入依赖的分支（如早期退出）不适用。
5. **未与现有异构框架直接比较**：虽然特征表比较了覆盖能力，但缺少端到端性能对比（不直接公平，可理解但遗憾）。
6. **功率测量精度**：使用封装功率传感器（HWInfo64），可能包含无关开销。
7. **均匀模型收益有限**：对Transformer等同质模型，顺序异构几乎无提升（<2%），潜在用户可能认为价值有限。
8. **计算表格仅报告部分最佳结果**：缺少所有配置的详细性能分布（如各模型在顺序、并行、并发下的完整原始延迟数值），仅报告归一化加速。
