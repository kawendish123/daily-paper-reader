## 摘要
高效视频编码（HEVC）中的递归四叉树划分带来了巨大的计算开销，穷举率失真优化用于CTU划分预测消耗了编码时间的绝大部分。尽管通过深度学习进行划分预测已成为一种可行的编码加速器，但架构上的二分法仍未得到充分解决：CNN计算效率高，但由于其局部有效感受野而在空间上目光短浅，无法捕捉长程语义关系和重复纹理；相反，基于变换器的架构更擅长捕捉全局上下文，但会导致难以承受的CPU延迟，这是一个关键缺陷，阻碍了主要受CPU限制的部署。本文介绍了混合快速视觉变换器（HFViT），这是一种混合架构，旨在加速HEVC帧内模式划分预测。HFViT融合了重新参数化的深度可分离卷积骨干与层次注意力变换器（HAT）机制，利用载体令牌方案以亚二次复杂度实现高效的全局信息传播。训练后结构融合将批归一化合并到前一层中，进一步降低延迟。综合评估揭示了HFViT在跨分辨率加速HEVC帧内编码方面的有效性。在标准JCT-VC测试序列上，与竞争性的ETH-CNN基线相比，HFViT在A类、B类和E类上分别将平均VMAF BD率惩罚降低了2.4、2.6和7.9个百分点，同时将CPU推理延迟控制在CNN基线的8%以内，并且在GPU上超过基线40%，为实时编码器集成建立了实际可行性。

## Abstract
The recursive quad-tree partitioning in High Efficiency Video Coding (HEVC) incurs considerable computational overhead, with exhaustive rate-distortion optimization for CTU partition prediction consuming the dominant share of encoding time. Although partition prediction through deep learning has emerged as a viable encoding accelerator, an architectural dichotomy remains largely unaddressed: CNNs are computationally efficient but spatially myopic due to their localized effective receptive fields, failing to capture long range semantic relationships and repetitive textures; conversely, transformer based architectures are better at capturing global context but incur prohibitive CPU latency, a critical liability that impedes deployment which is predominantly CPU-bound. This paper introduces Hybrid Fast Vision Transformer (HFViT), a hybrid architecture designed to accelerate HEVC intra-mode partition prediction. HFViT fuses a reparameterized depthwise-separable convolutional backbone with a Hierarchical Attention Transformer (HAT) mechanism, leveraging a carrier token scheme to enable efficient global information propagation at sub-quadratic complexity. Post-training structural fusion collapses batch normalization into preceding layers to further reduce latency. Comprehensive evaluation reveals the efficacy of HFViT in accelerating HEVC intra-encoding across resolutions. On standard JCT-VC test sequences, HFViT reduces the average VMAF BD-rate penalty by 2.4, 2.6, and 7.9 percentage points on Classes A, B and E, respectively, as compared to the competing ETH-CNN baseline while maintaining CPU inference latency within 8% of the CNN baseline and surpassing it on GPU by 40%, establishing practical viability for real-time encoder integration.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：HEVC/H.265 采用递归四叉树对编码树单元进行划分，划分决策依赖穷举率失真优化（RDO），消耗约 60%~80% 的编码时间。传统加速方法使用手工特征（纹理方差、梯度等）实现早期终止，只能获得 30%~45% 的速度提升，且带来 1.5%~3.0% 的 BD-rate 损失。

- **核心矛盾**：  
  - **CNN** 计算效率高、GPU 友好，但其有效感受野有限（高斯分布导致中心像素贡献大），难以捕获长程语义关系和重复纹理。  
  - **Vision Transformer** 能建模全局上下文，但自注意力的二次复杂度导致 CPU 推理延迟过高（如 ViT 在 CPU 上需 4.77 ms/CTU，是 CNN 基线 0.25 ms 的 19 倍），而实际编码器部署多为 CPU 密集型，GPU 加速不具普遍性。

- **问题定义**：需要在 **CPU 延迟接近 CNN 基线** 的前提下，引入 **全局上下文建模能力** 来提升 HEVC 帧内 CU 划分预测的率失真性能，实现可实用的编码加速器。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体架构

HFViT 融合 **重参数化深度可分离卷积骨干** 与 **层次注意力 Transformer (HAT)**，架构流：  
`单通道 CTU (64×64) → 四阶段深度可分离卷积下采样 → 双 HAT 块（含载体令牌交互） → QP 条件分类头 → 21 维划分概率输出`

### 2.2 关键技术细节

- **深度可分离卷积骨干**：  
  - 4 个下采样阶段，输出特征图尺寸：`32×32×8 → 16×16×16 → 8×8×24 → 4×4×32`。  
  - 使用深度可分离卷积减少参数量和计算量，通道扩展保守（8→16→24→32）以避免过拟合。  
  - 前三个阶段含残差块，第四个阶段无残差。

- **层次注意力 Transformer (HAT)**：  
  - **载体令牌机制**：将 4×4 特征图划分为 4 个 2×2 窗口，每个窗口自适应平均池化生成一个载体令牌（共 4 个）。  
  - **HAT-1**：窗口内自注意力：空间令牌（加位置编码后）与载体令牌拼接 → 层归一化 → 多头自注意力（2 头，每头 16 维）→ 残差 → FFN（扩展比 2）。相对位置偏置加入注意力 logits。  
  - **载体令牌交互层**：4 个载体令牌组成 4×32 矩阵，通过自注意力（无 FFN）交换全局信息，输出更新后载体令牌。  
  - **HAT-2**：用全局更新后的载体令牌再次与各窗口空间令牌进行注意力，融合局部与全局信息。  
  - **复杂度**：窗口内注意力为 O(N_win^2)，全局载体注意力为 O(N_win^2)，总体亚二次复杂度。

- **QP 条件分类头**：  
  - 全局平均池化后得 32 维特征，与归一化 QP（q/51）拼接成 33 维。  
  - 三层 MLP（BN + Dropout + ReLU），最终 Sigmoid 输出 21 维（深度 0:1 个、深度 1:4 个、深度 2:16 个划分概率）。  
  - 通过显式 QP 注入，单个模型可适应 QP = {22, 27, 32, 37} 的编码质量。

- **批归一化融合**：  
  - 训练时保留 BN，推理时将 BN 的 γ, β, μ, σ² 融合进前层卷积/全连接权重（W, b），消除 BN 前向传播开销。  
  - 融合公式：`Ŵ = γ/(√(σ²+ε)) * W`，`b̂ = γ(b-μ)/(√(σ²+ε)) + β`。

- **损失函数**：层次化二元交叉熵，对每个深度层级根据父块是否划分进行掩码，确保无效子块不计入损失。

## 6. 主要结论与发现

1. **HFViT 在 RD 性能上全面优于 CNN 基线**：  
   - 在 JCT-VC Class A/B/E 上，HFViT 的平均 VMAF BD-rate 分别为 3.12%、3.36%、6.03%，比 ETH-CNN 分别低 2.4、2.6、7.9 个百分点。  
   - 在所有指标（PSNR、VMAF、MS-SSIM）上，HFViT 均优于或持平于 ETH-CNN 和 H-FCN。

2. **CPU 延迟接近 CNN 基线**：  
   - HFViT CPU 延迟 0.27 ms/CTU，仅比 ETH-CNN（0.25 ms）高 8%，而之前最快的 Transformer（EfficientViT）为 0.50 ms（高 100%）。  
   - GPU 延迟 0.047 ms/CTU，比 ETH-CNN（0.078 ms）快 40%。

3. **载体令牌和 HAT 机制有效**：  
   - 层次注意力在亚二次复杂度下实现了全局上下文传播，高分辨率（4928×3264）上 HFViT 加速比达 79.41%，接近 ETH-CNN（78.57%），但 RD 性能明显更优。

4. **BN 融合是零性能代价的加速**：  
   - 消融实验表明：BN 融合不影响 BD-rate，但加速比从 55.56% 提升至 64.27%（提升 8.71 百分点）。

5. **QP 条件头实现单模型多 QP 适应**：  
   - 单个模型可处理四个 QP 值，避免了为每个 QP 单独训练模型，减少了部署开销。
