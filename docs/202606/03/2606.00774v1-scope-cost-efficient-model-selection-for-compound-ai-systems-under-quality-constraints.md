## 摘要
复合AI系统由多个LLM模块组成，共同处理超出单个模型能力的复杂多步骤任务。现有系统通常在所有模块中使用单一昂贵的LLM以提高整个系统的结果质量。然而，这种配置会带来高昂的成本，特别是对于大规模数据管理和分析任务（如数据操作）。为此，我们形式化了复合AI系统的约束LLM选择问题，利用不同LLM的多样定价和能力，以较低成本实现有竞争力的质量。给定查询数据集和用户指定的质量阈值，我们旨在为每个模块选择一个LLM，以最小化系统的平均成本，同时确保整体质量满足要求阈值。为了解决这个问题，我们提出了SCOPE，一种成本高效的优化算法。与依赖昂贵数据集级别评估的现有方法不同，SCOPE利用每个查询的结果快速估计系统的成本和质量，并构建置信界限来指导寻找有前途的LLM组合的搜索。此外，SCOPE提供了满足质量阈值和实现接近最优平均成本的理论保证。我们在三个数据处理任务上针对7个基线评估了SCOPE，证明它优于所有基线。在相同的搜索预算和质量约束下，它在搜索过程中找到的成本比最佳竞争者低20倍，并且在返回的解决方案中最终成本低6倍。

## Abstract
A compound AI system consists of multiple LLM modules, together handling complex and multi-step tasks that exceed the capabilities of a single model. Existing systems often use a single expensive LLM across all modules to improve the result quality of the whole system. However, this configuration incurs prohibitive costs, particularly for data management and analytics tasks at scale, such as data manipulation. To this end, we formalize the problem of constrained LLM selection for compound AI systems, leveraging the diverse pricing and capabilities of different LLMs to achieve competitive quality at lower cost. Given a query dataset and a user-specified quality threshold, we aim to select an LLM for each module to minimize the system's average cost while ensuring that overall quality meets the required threshold. To solve this problem, we propose SCOPE, a cost-efficient optimization algorithm. Unlike existing approaches that rely on expensive dataset-level evaluations, SCOPE exploits per-query results to rapidly estimate the system's cost and quality, and constructs confidence bounds to guide the search for promising LLM combinations. Furthermore, SCOPE provides theoretical guarantees for meeting the quality threshold and achieving near-optimal average cost. We evaluate SCOPE against 7 baselines on three data processing tasks, demonstrating that it outperforms all baselines. Under the same search budget and quality constraint, it finds solutions with up to $20\times$ lower cost than the best competitor during the search and achieves up to $6\times$ lower final cost in the returned solution.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：利用**查询级（per-query）**的细粒度评估，而非传统方法中需要在完整数据集上评估配置的方式，从而加速搜索过程。通过构建统计置信界限（confidence bounds）在探索与利用间平衡，并给出理论保证。
- **关键技术细节**：
    1. **概率置信区间**：为每个候选配置 $\boldsymbol{\theta}$ 维护成本 $c(\boldsymbol{\theta})$ 和约束 $g(\boldsymbol{\theta})$（定义为 $s_0 - s(\boldsymbol{\theta})$）的上下界 $L_{\zeta,t}(\boldsymbol{\theta})$ 和 $U_{\zeta,t}(\boldsymbol{\theta})$，使得真值以至少 $1-\delta$ 的概率落在区间内。
    2. **候选选择**：在每次迭代 $i$ 中，选择满足 $L_{g,t}(\boldsymbol{\theta}) \le -i^{-\alpha}$ 且成本下界 $L_{c,t}(\boldsymbol{\theta})$ 最小的配置 $\boldsymbol{\theta}_{\text{cand}}$（$\alpha \in (0,1/2)$ 为超参数）。该机制动态收紧约束条件。
    3. **顺序查询评估**：对选中的候选配置，按信息增益得分 $\varphi_i(q)$（基于高斯过程不确定度）降序依次评估查询 $q$，并在获得足够证据后立即剪枝（若显示不可行或无法优于当前最优解）。
    4. **界限校准（Calibrate）**：初始化阶段使用启发式方法，先评估多种配置在少量查询上的表现，逐步聚焦至最有潜力的配置并评估完整数据集，以获得较准确的初始界限。
    5. **理论保证**：论文证明了在亚高斯噪声和RKHS有界性假设下，SCOPE能以概率 $1-\delta$ 满足质量约束（$\delta$-correct），且简单遗憾（simple regret）以 $O(1/\sqrt{\tau})$ 速率收敛（$\tau$ 为观测次数），期望遗憾为 $O(\sqrt{\log \Lambda / \Lambda})$（$\Lambda$ 为搜索预算）。
- **算法流程（文字描述）**：
    1. 调用 `Calibrate` 获取初始观测和初始时间 $t_0$。
    2. 初始化置信界限，设当前最优解 $\boldsymbol{\theta}_{\text{out}} = \boldsymbol{\theta}_0$，当前最优上界 $U_{\text{out}} = U_{c,t_0}(\boldsymbol{\theta}_0)$。
    3. 循环迭代 $i=1,2,\dots$：
        - 按候选选择规则确定 $\boldsymbol{\theta}_{\text{cand}}$。
        - 对查询按 $\varphi_i(q)$ 降序排序。
        - 对每个查询 $q_{(j)}$：
            - 观测 $(\boldsymbol{\theta}_{\text{cand}}, q_{(j)})$，更新界限。
            - 若 $\boldsymbol{\theta}_{\text{cand}}$ 被证实可行且成本更优，则更新 $\boldsymbol{\theta}_{\text{out}}$ 和 $U_{\text{out}}$。
            - 若累计成本超预算 $\Lambda$，则终止所有循环。
            - 若 $\boldsymbol{\theta}_{\text{cand}}$ 被证明不可行或无法超越当前最优，则提前终止（剪枝）。
    4. 返回 $\boldsymbol{\theta}_{\text{out}}$ 和停止时间 $\tau$。
