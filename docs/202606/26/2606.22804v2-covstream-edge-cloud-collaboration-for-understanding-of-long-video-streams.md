## 摘要
长连续视频流日益成为多媒体智能的关键驱动力。现有工作通常采用“采样-编码-推理”的方式，利用大型模型处理长视频。然而，它们忽略了一个关键部署事实：视频流通常由计算受限的设备生成。这导致了一个难以维持的权衡：卸载到云端能实现强推理，但会带来高昂的带宽开销，而设备端处理则受限于边缘硬件能力。因此，我们提出了CoVStream，这是首个用于理解长视频流的边缘-云协作框架。边缘节点将原始视频流蒸馏为紧凑的视觉特征和语义描述，传输到云端以最小化带宽成本；云端服务器将这些数据整合到实体图和全局视觉上下文中，仅在用户查询到达时激活重型推理模型。在VideoMME-Long、LVBench和RTV-Bench上的实验表明，CoVStream在LVBench上将带宽使用量减少了87.6%，同时保留了云端基线精度的99.2%。

## Abstract
Long, continuous video streams are an increasingly critical driver of multimedia intelligence. Existing efforts often handle long videos with a sample-encode-reason approach using large models. However, they overlook a crucial deployment fact: the stream is often produced by computationally constrained devices. This forces an untenable compromise: cloud offloading unlocks strong reasoning but incurs prohibitive bandwidth overhead, while on-device processing remains limited by edge hardware capacity. Therefore, we propose CoVStream, the first edge-cloud collaborative framework for understanding long video streams. The edge node distills raw video streams into compact visual features and semantic captions for transmission to the cloud, minimizing bandwidth costs, while the cloud server integrates this data into an entity graph and global visual context, activating the heavy reasoning model only when a user query arrives. Experiments on VideoMME-Long, LVBench, and RTV-Bench show that CoVStream reduces bandwidth usage by 87.6% while retaining 99.2% of the cloud baseline accuracy on LVBench.

## 2. 方法论

- **核心思想**：利用视频流中的时空冗余，将边缘作为语义压缩器，云端专注于长时记忆维护与查询驱动的推理；通过“双端异步、训练无关”的设计实现高效协作。
- **关键技术细节**：
  - **边缘节点（双流感知与冷凝流水线）**：
    1. **视觉特征提取**：使用轻量级视觉编码器（0.4B）逐帧提取特征，送入特征队列。
    2. **时间特征冷凝**：对特征队列内的Ntemp帧进行迭代合并（余弦相似度最高的相邻对求均值），压缩至Ntarget帧，实现87.5%压缩率。
    3. **自适应关键帧选择**：并行地，对Nw帧进行聚类（Silhouette系数优化），选出代表帧作为关键帧。
    4. **语义描述生成**：使用Qwen3-VL-2B模型为关键帧生成简单句描述；最终载荷Pload = {冷凝特征, 描述文字}上传云端。
  - **硬件感知并行调度**：特征提取和描述生成分配至GPU，聚类和合并分配至CPU，避免资源竞争，帧处理延迟从64.98ms降至52.03ms。
  - **云端服务器（解耦管理+按需推理）**：
    - **记忆管理**（持续运行）：
      - 全局视觉上下文维护：冷凝特征通过迭代合并存入有限容量（Nbank=128）的压缩库，防止内存饱和。
      - 实体图构建：对描述文字进行句法解析（SVO三元组）、动态实体融合（利用NLI分类器判断双向蕴含）、向量化挂载（Qwen3-Embedding-0.6B编码后挂载到实体节点）。
    - **按需推理**（休眠-唤醒机制）：仅在收到用户查询触发时激活，执行：
      1. 查询向量化与余弦相似度检索top-k相关描述。
      2. 以锚点节点为中心提取一阶邻域子图（JSON序列化）。
      3. 将子图+全局视觉上下文+原始查询输入LMM（VideoLLaMA3-7B）生成响应。
  - **算法流程**：边缘持续执行感知→云端实时构建图与上下文→用户查询触发子图检索+LMM推理→返回答案。

## 3. 实验设计

- **数据集与场景**：三个流式视频理解基准：
  - **VideoMME-Long**：6个视觉领域、30个子域，平均时长3160秒，900个单选择题。
  - **LVBench**：极长视频理解，选取>2800秒子集，平均5018秒，1007个问题。
  - **RTV-Bench**：实时流式视频，167.2小时，平均1092秒/段，涵盖自我中心、智能驾驶、体育分析。
- **基线方法**：
  - **Local-Only (LO)**：轻量VideoLLaMA3-2B纯端侧推理，低精度、无带宽。
  - **Cloud-Only (CO)**：VideoLLaMA3-7B云端处理原始帧（1 FPS），高带宽、高精度上限。
  - **Edge-Cloud (EC)**：边缘抽帧+4倍降采样后上传，云端AuraSR-v2超分后再推理。
- **对比指标**：准确率、通信量（MB）、压缩率、端到端延迟。

## 7. 优点

- **创新性**：首次将边缘-云协作系统性地应用于长视频流理解，巧妙结合语义压缩与图增强记忆，且是训练无关（training-free），可直接集成不同LMM。
- **高效性**：异步解耦设计使边缘特征提取、云端记忆管理、按需推理并行进行，延迟低于云卸载；硬件感知调度进一步降低端侧延迟。
- **可扩展性**：实体图结构使记忆随视频长度平稳增长（而非线性），适合始终在线场景。
- **实验全面**：覆盖多基准、多时长、多硬件，并包含模拟24小时连续流的压力测试。
- **实用性**：边缘端要求低（8GB GPU可行），带宽降低约88%，精度接近云端上限，具备实际部署潜力。

## 8. 不足与局限

- **实验覆盖**：缺乏与现有更先进的边缘-云视频分析系统（如基于知识蒸馏或分层推理的方法）的直接对比；基线EC仅采用简单的降采样+超分，代表性有限。
- **评估偏差风险**：所有实验在模拟环境下进行，未在真实低功耗边缘设备（如手机、智能眼镜SoC）上部署验证；边缘端延迟（52.03ms/帧）仅为GPU测试结果，未考虑网络传输抖动、电池功耗等因素。
- **图构建依赖**：实体图质量受限于NLI分类器（NLI-Deberta-v3）和句法解析器（SpaCy），在复杂场景或非英语视频中可能引入错误；且“严格简单句”提示可能丢失细节信息。

- **查询驱动局限**：只适用于有明确用户查询的场景；对于无查询的主动监控或摘要生成任务需额外适配。
